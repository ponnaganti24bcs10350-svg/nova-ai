## 🌌 THE VISION

What if AI could do more than just respond?

What if it could understand situations, recognize potential risks, coordinate intelligent workflows, and help people when they need it most?

**NOVA** explores this vision.

Nova is an AI-powered Adaptive Guardian designed around intelligent assistance, safety-oriented workflows, and emergency escalation.

By combining AI integration, backend engineering, and the **Model Context Protocol (MCP)**, Nova explores how intelligent systems can become more proactive, contextual, and responsible.

> 💡 Building AI that doesn't just understand — but knows when something needs attention.

## ⚡ GETTING STARTED

Want to explore Nova? Get started locally.

### 1. Clone the repository

```bash
git clone https://github.com/ponnaganti24bcs10350-svg/nova-ai.git
```

### 2. Navigate to the project

```bash
cd nova-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file:

```env
PORT=10000
```

Add any additional environment variables required by your implementation.

### 5. Run the application

Use the startup command configured in your `package.json`.
